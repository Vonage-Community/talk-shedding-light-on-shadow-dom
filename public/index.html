Shedding Light on the Shadow DOM

A step-by-step walkthrough of the Shadow DOM and Web Components APIs — from imperatively attaching a shadow root all the way to form-associated custom elements.

Step 01 Imperatively Creating a Shadow Root Call attachShadow() at runtime and see how it replaces light DOM content with an isolated shadow tree. Step 02 CSS Parts — Broken Watch regular CSS selectors fail to pierce the shadow boundary, even when the rules look correct. Step 03 CSS Parts — Fixed Use ::part() to reach inside a shadow root once the component author opts in with part attributes. Step 04 exportparts Forward inner component parts outward with exportparts so page CSS can cross two shadow boundaries at once. Step 05 Slots Project light DOM content into a shadow root with named slots — and keep it styleable from the page. Step 06 Lifecycle Callbacks See constructor, connectedCallback, disconnectedCallback, and attributeChangedCallback fire in real time. Step 07 Form-Associated Elements — Broken Custom elements without formAssociated are invisible to FormData — submit the form and watch the values disappear. Step 08 Form-Associated Elements — Fixed Add static formAssociated = true and attachInternals() to unlock native validation and proper form submission.
