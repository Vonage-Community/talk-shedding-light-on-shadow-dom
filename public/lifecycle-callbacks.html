Lifecycle Callbacks

Custom elements have five lifecycle callbacks that fire at predictable moments. Navigate through the ships below — each action triggers one or more callbacks, logged to the console and to the panel on this page.

1 / 4

Each navigation removes the current element and adds a new one, triggering disconnectedCallback, constructor, and connectedCallback. Changing the ship's attributes while it stays in the DOM triggers attributeChangedCallback instead.
